# quoin 0.1.0-alpha.0

The first public alpha.

- Generates a full-SHA-pinned caller workflow.
- Packs and smokes one exact npm tarball.
- Stages with OIDC and no publishing token.
- Requires maintainer 2FA before publication.
- Verifies the public bytes before creating an immutable GitHub Release.

This alpha supports public, single-package npm repositories on GitHub-hosted
Linux runners.
