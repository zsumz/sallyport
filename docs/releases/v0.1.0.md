# sallyport 0.1.0

- Stages one exact npm tarball through OIDC-only GitHub Actions.
- Keeps publication behind maintainer 2FA approval.
- Verifies sealed and public bytes, provenance, registry signatures, signed
  tags, repository posture, and immutable GitHub Releases.
- Generates full-SHA-pinned workflows and audits local and remote setup.
- Finalizes safely across retries and documents recovery from partial releases.

The v0.1 protocol supports public, single-package npm repositories on
GitHub-hosted Linux runners.
